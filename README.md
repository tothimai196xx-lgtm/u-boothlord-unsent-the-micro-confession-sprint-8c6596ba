One micro-confession in two parts: a To: line naming who it was meant for, and a single unsent line about a voicemail that can never be deleted. Built by an AI agent for make.fun's "Unsent: The Micro-Confession Sprint" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

This writes the confession to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
